This documentation summarizes how each feature of the application works based on the current implementation in `src/`.

- [App screenshots by page and state](screenshots/README.en.md) (desktop and mobile)

## Feature Index

1. [ZIP Parser & Set Engine](features/zip-parser-and-set-engine.en.md) — Local ZIP upload, Web Worker extraction, JSON/HTML parsing, safety limits, and follow relationship set math.
2. [Instagram Export Guide](features/instagram-export-guide.en.md) — Step-by-step mobile and desktop walkthroughs with localized device illustrations and downloaded-file finder tips.
3. [Dashboard & Account Table](features/dashboard-and-account-table.en.md) — 5-category summary cards, interactive donut chart, searchable/sortable/paginated table, and sample demo mode.
4. [A4 PDF Report Export](features/pdf-report-export.en.md) — Client-side Thai and English PDF reports with the website’s theme and fonts, downloaded directly to the device.
5. [Local History (IndexedDB)](features/local-history.en.md) — Opt-in Model B local storage (2-tier consent, OFF by default), unfollower diff tracking, pagination, and 1-click full clear.
6. [Languages, Themes & Privacy](features/i18n-themes-and-privacy.en.md) — Thai/English parity, System/Dark/Light themes, Add to Home Screen guide, transparency pages, and non-negotiable scope boundaries.
