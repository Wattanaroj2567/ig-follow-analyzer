# ประวัติย้อนหลังบนเครื่อง (Local History)

**ภาษาไทย** · [English](local-history.en.md)

## ภาพรวม

เก็บประวัติผลการวิเคราะห์ไว้ในเบราว์เซอร์ของผู้ใช้ (`IndexedDB`) เพื่อเปรียบเทียบความเปลี่ยนแปลงของผู้ติดตามระหว่างรอบการส่งออกไฟล์ โดยยึดหลัก Privacy-first (Model B)

หน้าแรกแสดงวิธีเริ่มตั้งแต่เปิดบันทึกสรุปและจำรายชื่อ วิเคราะห์ ZIP ทีละไฟล์ แล้วกลับมาอัปโหลด ZIP ใหม่ของบัญชีเดิมในเบราว์เซอร์เดิม พร้อมอธิบายว่าหน้าผลล่าสุดให้เลือกไฟล์ย้อนหลังได้ หากอยากเห็นความเปลี่ยนแปลงชัดขึ้น ลองขอ ZIP ใหม่วันถัดไปหรือหลังจากนั้น เพราะไฟล์ที่ขอวันเดียวกันอาจมีรายชื่อเหมือนกัน

หน้าผลวิเคราะห์มีการ์ด **ติดตามใหม่** และ **หายจากรายชื่อ** แตะการ์ดเพื่อเปิดรายชื่อ แล้วแตะบัญชีเพื่อดูไทม์ไลน์ของสองไฟล์ ระบบแสดงวันที่เริ่มติดตามเมื่อมีข้อมูลในไฟล์ ส่วนการหายจากรายชื่อแสดงด้วยสถานะที่พบในแต่ละรอบ ผู้ใช้ลองดูผลและไทม์ไลน์ด้วยข้อมูลสมมติจากหน้าแรกได้

ผลล่าสุดแสดงชื่อ ZIP วันที่ของไฟล์ และเวลาวิเคราะห์ทั้งสองฝั่ง ระบบเลือกไฟล์ก่อนหน้าที่มีรายชื่อบันทึกไว้ของบัญชีเดียวกันอัตโนมัติ ถ้ามีไฟล์ย้อนหลังให้เลือกหลายรอบ กด **เปลี่ยนไฟล์ย้อนหลัง** แล้วเลือกไฟล์ที่ต้องการ ยอดและไทม์ไลน์อัปเดตตามคู่ที่เลือก กด **กลับไปเทียบรอบก่อนหน้า** เพื่อใช้ค่าอัตโนมัติอีกครั้ง ไฟล์วันเดียวกันเรียงตามเวลาวิเคราะห์

ในหน้าประวัติ เลือกรายการย้อนหลังแล้วกด **สร้าง PDF เทียบกับไฟล์ล่าสุด** เพื่อเปิดพรีวิวพร้อมคู่ที่เลือก ปุ่มจะแสดงเมื่อเปิดการจำรายชื่อและมีรายชื่อบันทึกไว้ทั้งในรอบที่เลือกและ ZIP ล่าสุดของบัญชีเดียวกัน

กด **ดูประวัติตัวอย่าง** จากหน้าแรกหรือแดชบอร์ดตัวอย่างเพื่อดูไฟล์ล่าสุด 2 รอบ หรือเปิดทั้งหมดทีละ 4 รอบ ลองเปิดแดชบอร์ดของแต่ละไฟล์หรือสร้าง PDF เทียบกับไฟล์ล่าสุดจากรายการย้อนหลังได้ หน้าตัวอย่างใช้ข้อมูลสมมติในแอปและไม่เข้าถึงประวัติจริงใน `IndexedDB`

## ความสามารถหลัก

- **ปิดเป็นค่าเริ่มต้น (OFF by default):** แอปจะไม่บันทึกประวัติใดๆ จนกว่าผู้ใช้จะกดเปิดความยินยอมเอง
- **ความยินยอมแบบ 2 ชั้น (2-Tier Opt-In):**
  - **ชั้นที่ 1 (`tier1SummaryOptIn`):** บันทึกเฉพาะสรุปตัวเลขและข้อมูลเมตาของแต่ละรอบ
  - **ชั้นที่ 2 (`tier2HandlesOptIn`):** บันทึกรายชื่อไว้กับประวัติแต่ละรอบเพื่อเปิดดูซ้ำและใช้เปรียบเทียบย้อนหลัง รายการที่บันทึกเฉพาะสรุปยังดูได้ในประวัติ
- **แยกข้อมูลตามบัญชี:** ใช้ชื่อบัญชีเจ้าของจากชื่อ ZIP เดิมที่ Instagram ส่งออก การเปรียบเทียบไฟล์จริงต้องระบุได้ว่าทั้งคู่เป็นบัญชีเดียวกัน และโหมดตัวอย่างใช้ชุดข้อมูลสมมติแยกต่างหาก
- **ควบคุมและลบได้ตลอดเวลา:** แบ่งหน้ารายการประวัติทีละ 5 รายการเพื่อไม่ให้หน้ายาวเกินไป พร้อมรองรับการลบทีละรายการหรือล้างข้อมูลทั้งหมดในคลิกเดียวหลังยืนยัน
