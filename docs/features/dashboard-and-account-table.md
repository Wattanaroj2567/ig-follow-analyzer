# แดชบอร์ดและตารางรายชื่อ

**ภาษาไทย** · [English](dashboard-and-account-table.en.md)

## ภาพรวม

แสดงผลสรุปความสัมพันธ์ผู้ติดตามทั้งหมดในหน้าเดียว พร้อมกราฟวงกลม ตารางรายชื่อที่ค้นหาและจัดเรียงได้ และโหมดข้อมูลตัวอย่างสำหรับให้ทดลองใช้งานก่อนอัปโหลดไฟล์จริง

## ความสามารถหลัก

- **การ์ดสรุป 5 หมวด (คำนวณจาก Set Engine):**
  - ผู้ติดตาม (`Followers`)
  - กำลังติดตาม (`Following`)
  - ไม่ได้ติดตามกลับ (`Not Following Back`)
  - คุณไม่ได้ติดตามกลับ (`Not Followed Back`)
  - ติดตามกันและกัน (`Mutual`)
- **กราฟวงกลมแบบโต้ตอบได้:** รายการสีแสดงจำนวนและเปอร์เซ็นต์แยกตามหมวด ชี้เพื่อดูจำนวนของหมวดนั้นกลางกราฟ หรือแตะเพื่อค้างค่าไว้ แตะอีกครั้งเพื่อล้างตัวเลขกลางกราฟ
- **ตารางรายชื่อบัญชี:**
  - ค้นหาด้วยชื่อบัญชี (handle)
  - กรองตามหมวดความสัมพันธ์ทั้ง 5 หมวด เมื่อมีผลเทียบ ให้เปิด **ติดตามใหม่** หรือ **หายจากรายชื่อ** แล้วกางไทม์ไลน์รายบัญชีได้
  - การ์ด **ติดตามใหม่** และ **หายจากรายชื่อผู้ติดตาม** บอกจำนวนและไฟล์ที่พบชื่อ ตัวอย่างใต้การ์ดอธิบายว่าบัญชีที่พบเฉพาะใน ZIP ที่ใช้เทียบจะอยู่ในหมวด **หายจากรายชื่อผู้ติดตาม**
  - หัวข้อผลเทียบแสดงชื่อ ZIP ทั้งสองฝั่ง ในฝั่ง **เทียบกับ** ใช้ **เปลี่ยนไฟล์ย้อนหลัง** เพื่อเลือก ZIP ของบัญชีเดียวกันที่บันทึกรายชื่อไว้ หรือกลับไปใช้รอบก่อนหน้าที่ระบบเลือกอัตโนมัติ
  - เรียงลำดับตามวันที่หรือชื่อบัญชี และแบ่งหน้าอัตโนมัติ (25 รายการต่อหน้า)
  - ลิงก์เปิดหน้าโปรไฟล์ Instagram ในแท็บใหม่ด้วย URL ที่ผ่านการ sanitize แล้ว
  - แสดงวันที่ติดตามทั้งสองฝั่งในหมวดติดตามกันและกัน (เมื่อไฟล์เป็น JSON) และแสดงคำอธิบายชัดเจนเมื่อไฟล์เป็น HTML ที่ไม่มี timestamp
- **โหมดตัวอย่าง (Demo Mode):** พรีวิวหน้าแรกเริ่มที่ภาพรวมไฟล์เดียวและเลือกดูได้ 5 หมวด เมื่อเลือก **เทียบ 2 รอบ** จะเห็นวันที่ของทั้งสองไฟล์และสลับดูรายชื่อที่เริ่มติดตามหรือหายจากรายชื่อได้ กด **ลองดูผลเทียบ 2 รอบ** ในส่วน **ดูว่าใครเพิ่งเลิกติดตาม** เพื่อเปิดแดชบอร์ดเต็ม เลือก ZIP ย้อนหลัง และดูไทม์ไลน์
- **วิเคราะห์ไฟล์จริงรอบแรก:** แสดงภาพรวมของรอบนั้นและแนะนำให้เปิดบันทึกประวัติกับจำรายชื่อเพื่อเทียบ ZIP รอบถัดไป
