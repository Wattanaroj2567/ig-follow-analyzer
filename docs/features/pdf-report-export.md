# รายงาน PDF A4

**ภาษาไทย** · [English](pdf-report-export.en.md)

## ภาพรวม

สร้างรายงานสรุปผลความสัมพันธ์ผู้ติดตามเป็นเอกสาร PDF ขนาด A4 ในเบราว์เซอร์โดยตรง และดาวน์โหลดลงอุปกรณ์ของผู้ใช้ทันที (บน iOS / Android สามารถเลือกบันทึกเข้าแอป Files หรือแอป Google Drive บนเครื่องผ่านเมนู Native ของระบบปฏิบัติการได้เลยโดยไม่ต้องผูกบัญชี OAuth กับเว็บไซต์)

## ความสามารถหลัก

- **สร้างเอกสาร PDF A4 บนเครื่อง (`pdfmake`):**
  - พรีวิว A4 และไฟล์ที่ดาวน์โหลดใช้ฟอนต์ `TH Sarabun New` จาก `public/fonts/` โดยเบราว์เซอร์โหลดเฉพาะน้ำหนักที่ใช้ในพรีวิว และ `pdfmake` ฝังฟอนต์ที่ใช้ลงในไฟล์เพื่อให้เลือกและคัดลอกข้อความภาษาไทยได้
  - รองรับการโหลดฟอนต์แบบ subpath-safe สำหรับการเผยแพร่บน GitHub Pages
  - มีตัวเลือกชุดหัวข้อด่วน (`แบบแนะนำ`, `ไม่ฟอลกลับ`, `ครบทุกหมวด`) พร้อมคำนวณจำนวนหน้าและจำนวนบัญชีแบบเรียลไทม์
  - พรีวิว A4 แบบเต็มจอจะปรับตามความกว้างที่มีบนมือถือและคอมพิวเตอร์ เลื่อนดูต่อเนื่องได้หลายหน้าและซูมได้ `60%–180%` เทียบกับขนาดที่พอดีจอ
  - รายการสีของกราฟวงกลมแสดงจำนวนและเปอร์เซ็นต์ของความสัมพันธ์ทั้ง 3 กลุ่ม ทั้งในพรีวิวและไฟล์ PDF
  - ตัวเลขสรุปและหัวตารางใช้สีที่มีคอนทราสต์ชัดเจนแยกตามหมวด ชุด `ครบทุกหมวด` รวมรายชื่อทั้งสองกลุ่มที่ไม่ได้ติดตามกลับและรายชื่อผู้ติดตามทั้งหมด
  - รองรับทั้งภาษาไทยและภาษาอังกฤษสำหรับทั้งรายงานจากไฟล์จริงและรายงานตัวอย่าง (ซิงก์ตามภาษาหน้าเว็บและเลือกสลับภาษาเอกสารได้โดยตรงในหน้าสร้าง PDF)
