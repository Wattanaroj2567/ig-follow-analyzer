# คู่มือขอไฟล์จาก Instagram

**ภาษาไทย** · [English](instagram-export-guide.en.md)

## ภาพรวม

คู่มือแบบโต้ตอบในแอปสำหรับขอไฟล์ข้อมูลผู้ติดตาม (`.zip`) จากศูนย์บัญชี Instagram โดยเลือกเฉพาะข้อมูลผู้ติดตาม ตั้งช่วงวันที่เป็น **ตั้งแต่ต้น** บนมือถือหรือ **ตลอดเวลา** บนคอมพิวเตอร์ และเลือกรูปแบบ `JSON`

ลิงก์ **ดูขั้นตอนเลือกช่วงตลอดเวลา** ในคำเตือนหน้าผลวิเคราะห์จะพาไปยังขั้นเลือกช่วงวันที่ของคู่มือโดยตรง

## ความสามารถหลัก

- **แยกขั้นตอนตามอุปกรณ์:**
  - **มือถือ (แอป Instagram):** 19 ขั้นตอน เลือกรูปแบบ **JSON** แล้วแตะ **บันทึก** เพื่อกลับมาหน้ายืนยัน จากนั้นแตะ **เริ่มส่งออก** เมื่อไฟล์พร้อมและแตะดาวน์โหลดที่แถว ZIP ให้ยืนยันรหัสผ่านในศูนย์บัญชี บน iPhone ให้แตะ **บันทึก…** ที่แถบดาวน์โหลด แล้วรอจนขึ้น **ดาวน์โหลดเสร็จสมบูรณ์** ก่อนแตะ **เปิดใน…** เพื่อบันทึกไปยังแอปไฟล์
    บน Android เบราว์เซอร์จะเปิดและดาวน์โหลด ZIP อัตโนมัติ ให้ข้ามขั้นที่ 17–18 ซึ่งใช้เฉพาะ iPhone แล้วไปขั้นที่ 19 เพื่อหาและเลือกไฟล์ ZIP
  - **คอมพิวเตอร์ (Web):** 15 ขั้นตอนผ่านเบราว์เซอร์ แยกการบันทึกรูปแบบ JSON ออกจากการเริ่มส่งออก เมื่อไฟล์พร้อมให้คลิกดาวน์โหลดที่แถว ZIP และยืนยันรหัสผ่านในศูนย์บัญชี จากนั้นหาไฟล์เดิมแล้วเลือกในหน้าวิเคราะห์โดยไม่ต้องแตกไฟล์
- **ภาพจำลองหน้าจอสองภาษา:** แสดงภาพจำลอง UI ตามภาษาที่ผู้ใช้เลือก (ไทย / อังกฤษ) พร้อมไฮไลต์จุดที่ต้องกดในแต่ละขั้น โดยใช้ชื่อบัญชีสมมติ (`@somchai.demo`) และไม่ใช้โลโก้หรือเครื่องหมายการค้าของ Instagram/Meta
- **เช็กสถานะหลังขอไฟล์:** ใช้ทางลัดในคู่มือเพื่อดูวิธีเข้า **ส่งออกข้อมูลของคุณ → กิจกรรมปัจจุบัน** แล้วดาวน์โหลดไฟล์ที่พร้อม แม้ยังไม่ได้รับอีเมลแจ้งเตือน
- **หน้าทำไมต้องใช้ไฟล์ ZIP:** เปิดจากหน้าแรกเพื่อดูตารางเปรียบเทียบ Instagram Login กับ ZIP และไปต่อที่คู่มือขอไฟล์
- **คำแนะนำหาไฟล์ที่ดาวน์โหลดไว้:** ในหน้าอัปโหลดมีส่วนกางคำแนะนำช่วยหาไฟล์ `.zip` บนมือถือและคอมพิวเตอร์ กรณีผู้ใช้ดาวน์โหลดแล้วแต่หาไฟล์ไม่เจอ
