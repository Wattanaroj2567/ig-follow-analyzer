## ฟีเจอร์

- **แดชบอร์ดผู้ติดตาม** ดูว่าใครติดตามคุณ คุณติดตามใคร ใครติดตามกัน ใครไม่ติดตามคุณกลับ และใครที่คุณยังไม่ได้ติดตามกลับ พร้อมค้นหา กรอง และเรียงรายชื่อ
- **สัดส่วนความสัมพันธ์** ดูว่าเปอร์เซ็นต์แต่ละค่ามาจากตัวเลขใดในผลวิเคราะห์
- **วิเคราะห์ ZIP ในเบราว์เซอร์** รองรับไฟล์ส่งออกจาก Instagram ทั้ง JSON และ HTML โดยไฟล์ ZIP อยู่บนอุปกรณ์ของคุณ
- **เทียบไฟล์สองช่วงเวลา** ดูว่าผู้ติดตามรายใดเพิ่มขึ้นหรือหายไประหว่าง ZIP สองไฟล์ของบัญชีเดียวกัน ประวัติปิดเป็นค่าเริ่มต้นและล้างได้ทุกเมื่อ
- **รายงาน PDF ขนาด A4** ดาวน์โหลดผลการวิเคราะห์เป็นภาษาไทยหรืออังกฤษ
- **ข้อมูลตัวอย่างและคู่มือขอไฟล์** ลองใช้แดชบอร์ดด้วยบัญชีสมมติ แล้วทำตามคู่มือเพื่อขอ ZIP ของคุณเอง
- **คำถามเรื่องเทียบไฟล์** ดูว่าควรทำอะไรเมื่อมี ZIP รอบแรก ZIP รอบใหม่ หรือเลือกไฟล์เดิมซ้ำ
- **ภาษาและธีม** ใช้งานเป็นภาษาไทยหรืออังกฤษ พร้อมธีมตามระบบ มืด และสว่าง

## วิธีใช้งาน

ลองใช้ข้อมูลตัวอย่างจากหน้าแรก หรือทำตามขั้นตอนนี้ด้วยไฟล์ของคุณเอง

1. **ขอไฟล์ ZIP** ในศูนย์บัญชี Instagram เลือก **ผู้ติดตามและกำลังติดตาม** ตั้งช่วงเวลาเป็น **ตั้งแต่ต้น** บนมือถือหรือ **ตลอดเวลา** บนคอมพิวเตอร์ แล้วเลือก **JSON** ดาวน์โหลด ZIP เมื่อไฟล์พร้อม
2. **วิเคราะห์ ZIP** ถ้าต้องการเทียบผลในภายหลัง ให้เปิดประวัติในเครื่องและอนุญาตให้บันทึกรายชื่อก่อน จากนั้นเลือก ZIP ในแอป
3. **ดาวน์โหลดรายงาน** ในหน้าผลวิเคราะห์ กด **สร้างรายงาน PDF** แล้วดาวน์โหลดลงอุปกรณ์

### เทียบผลย้อนหลัง (ไม่บังคับ)

กลับมาใช้เบราว์เซอร์เดิมกับ ZIP ใหม่ของบัญชีเดียวกัน หน้าผลจะแสดงว่าผู้ติดตามรายใดเพิ่มขึ้นหรือหายไปจากไฟล์ก่อนหน้าที่บันทึกไว้ [คู่มือประวัติในเครื่อง](docs/features/local-history.md)

## แอปทำงานอย่างไร

`ไฟล์ ZIP จาก Instagram → Web Worker → แดชบอร์ด → PDF ขนาด A4`

| ส่วนประกอบ           | หน้าที่                        |
| ------------------- | --------------------------- |
| เว็บแอป              | แสดงผลการวิเคราะห์            |
| Web Worker · fflate | อ่าน ZIP และคำนวณความสัมพันธ์   |
| PDF · pdfmake       | สร้างรายงานขนาด A4           |
| ประวัติ · IndexedDB   | เก็บข้อมูลที่ผู้ใช้อนุญาตในเบราว์เซอร์ |

เว็บแอปใช้ React, TypeScript, Vite และ Tailwind CSS

ทั้งการวิเคราะห์ ZIP และการสร้าง PDF ทำบนอุปกรณ์ แอปใช้งานได้โดยไม่ต้องมีบัญชีหรือกรอกข้อมูลเข้าสู่ระบบ Instagram [ความเป็นส่วนตัวและขอบเขต](docs/features/i18n-themes-and-privacy.md#ความเป็นส่วนตัวและขอบเขตที่ตั้งใจไม่รองรับ)

## รันในเครื่อง

ใช้ Node.js 24 และ npm รันคำสั่งจากโฟลเดอร์หลักของโปรเจกต์ แล้วเปิด URL ที่ Vite แสดงในเทอร์มินัล

```bash
npm ci
npm run dev
```

### เปิดรับรีวิว (ไม่บังคับ)

ใช้ `npm run setup:env` เพื่อสร้าง `.env.local` จากไฟล์ตัวอย่าง จากนั้นตั้ง `VITE_REVIEW_ENDPOINT` เป็น URL เต็มของ Google Apps Script web app ที่ลงท้ายด้วย `/exec` ค่า endpoint นี้เป็นข้อมูลสาธารณะในไฟล์เว็บ [คู่มือตั้งค่าระบบรีวิว](docs/features/i18n-themes-and-privacy.md#เปิดระบบครั้งแรก)

### เผยแพร่บน Cloudflare Pages

ตั้ง build command เป็น `npm run build` และ output directory เป็น `dist` หากต้องการเปิดรับรีวิวบนเว็บจริง ให้ตั้ง `VITE_REVIEW_ENDPOINT` ใน environment ของ Production แล้ว deploy ใหม่
