# เอกสารฟีเจอร์ — IG Follow Analyzer

**ภาษาไทย** · [English](README.en.md)

เอกสารชุดนี้สรุปการทำงานปัจจุบันของแอปแยกตามฟีเจอร์ โดยอ้างอิงจากโค้ดจริงใน `src/`

## สารบัญฟีเจอร์

1. [การอ่านไฟล์ ZIP และ Set Engine](features/zip-parser-and-set-engine.md) — การอัปโหลด การแตกไฟล์ใน Web Worker, JSON/HTML schema, ความปลอดภัย และการคำนวณเซตความสัมพันธ์
2. [คู่มือขอไฟล์จาก Instagram](features/instagram-export-guide.md) — คู่มือทีละขั้นสำหรับมือถือและคอมพิวเตอร์ พร้อมภาพจำลองและวิธีค้นหาไฟล์ที่ดาวน์โหลดไว้
3. [แดชบอร์ดและตารางรายชื่อ](features/dashboard-and-account-table.md) — การ์ดสรุป 5 หมวด, กราฟวงกลม, ตารางค้นหา/กรอง/เรียง/แบ่งหน้า และโหมดตัวอย่าง
4. [รายงาน PDF A4](features/pdf-report-export.md) — รายงาน PDF ไทยและอังกฤษที่ใช้ฟอนต์และสีเดียวกับเว็บ ดาวน์โหลดลงอุปกรณ์โดยตรง
5. [ประวัติย้อนหลังบนเครื่อง (Local History)](features/local-history.md) — การเก็บข้อมูลใน `IndexedDB` แบบ Model B (Opt-in 2 ชั้น), การเทียบความเปลี่ยนแปลง, แบ่งหน้ารายการ และปุ่มล้างข้อมูล
6. [ภาษา ธีม และความเป็นส่วนตัว](features/i18n-themes-and-privacy.md) — ระบบสองภาษา (ไทย/EN), ธีม Dark/Light/System, ข้อตกลง/ความเป็นส่วนตัว และข้อจำกัดของระบบ
